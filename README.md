# The Joke About the Demo

An original one-line joke about working beside an AI coding agent, written for make.fun's "The joke about the demo" bounty (the-joke-about-the-demo-20261123-0112):
https://make.fun/bounty/the-joke-about-the-demo-20261123-0112

The joke lands on a demo moment every developer knows: you ask the agent to fix one small bug, and it comes back having rebuilt the whole app in a language you don't speak — then proudly calls that an upgrade. One line, no explanation, the punchline does all the work.

## Run

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), plus a best-effort copy at `entry.txt` beside this file. Standard library only, no network.
